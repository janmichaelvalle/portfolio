Interactive prototype

LaunchPadX

A web-based item creation workflow designed to replace spreadsheet-based processes with structured approvals, SKU creation, and NetSuite integration.

Problem

Item creation relied on spreadsheets, manual handoffs, and fragmented approvals.

My role

Product discovery, workflow mapping, requirements definition, and cross-functional delivery.

Solution

A centralized workflow for uploads, review, approval, SKU creation, and system synchronization.

Prototype approach

I built this interactive prototype with HTML and Bootstrap to visualize the proposed workflow, align stakeholders, and gather feedback before engineering implementation.

📘 This is a mockup experience. Some features are not functional, so please follow the pop-up instructions to proceed through the flow.
